# Changelog

## 0.1.0 — 2026-10-21

First developer preview of the format and reference implementation.

- MIT license for the project's original schemas, specification, documentation, examples, and implementation; third-party notices retained.

- Versioned authored-package, manifest, fragment, and resolved-value JSON Schemas.
- Twenty-seven reusable value types, with a pinned Figma foundation field baseline and explicit REST supplements.
- Separate resource identity, organization, references, native bindings, and color composition.
- Collection modes, themes, extended-collection views and inherited overrides.
- Offline exact dependencies, asset integrity, and bounded vector artwork.
- Reference validator, theme resolver, authoring-file assembler, JavaScript API, and CLI.
- Valid examples, static invalid fixtures, and behavioral conformance tests.
- Field reference, source baseline, usage guide, and third-party notices.
- Publication review fixes for malformed inputs, strict native alias types, validation options, pointer-boundary behavior, and canonical base64.
- Independent specification-driven regression cases, contributor and security policies, pinned GitHub workflows, and reproducible source bundles.

The format includes native Figma enum spelling, `itemId` for stack identity, an override-record array, easing/timing variables, six authored color spaces, explicit color/alpha composition, and a precise file/dependency contract.

This version is not a Figma plugin and does not claim live round-trip fidelity or support for features outside its documented foundation baseline.
