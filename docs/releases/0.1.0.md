# Figma Foundations Schema 0.1.0 — developer preview

An MIT-licensed format and reference implementation for reusable Figma Design foundations.

This release provides:

- Versioned JSON Schemas for authored packages, split-file manifests, and resolved value contracts.
- Stable resource identities, references, native property bindings, and explicit collection contexts.
- Variables, extended collections, paint/text/effect/grid/motion styles, property presets, themes, and asset dependencies.
- A local validator, theme resolver, assembler, examples, and conformance fixtures.
- A pinned Figma foundation field baseline, field reference, and documented REST/API normalization.

The download contains the specification, schemas, documentation, examples, reference implementation, tests, MIT license, and required third-party notices. Verify the archive with the accompanying `SHA256SUMS`; `RELEASE_MANIFEST.json` records the included source file hashes.

After extracting the archive, use Node.js 22 or newer:

```sh
npm ci
node src/cli.js validate examples/minimal.foundation.json
node src/cli.js resolve examples/surface.foundation.json --theme theme-dark
```

This is a developer preview, not a Figma plugin or an official Figma standard. It has not been tested for live Figma round-trip fidelity or visual equivalence. External shader/font/animation assets are dependencies, not promised bundled implementations. Components, screens, and per-node timelines are outside Foundations.

The first release includes review fixes for malformed inputs, native alias types, evaluation options, canonical base64, and pointer selection around native bindings. Later format changes will receive new versioned contracts rather than rewriting 0.1.0.
